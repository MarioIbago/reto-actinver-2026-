# Source Material

This directory stores **raw evidence and source snapshots** used by the project.

## Files

- `reto-actinver-2026-guia.md`
  - participant-guide snapshot supplied by the project owner;
  - contains competition mechanics and the 2026 annex of eligible instruments.

- `actinver_universe_symbols_raw.md`
  - compact at-hand list of the 207 symbols extracted from the guide;
  - useful for research prompts and source checks;
  - NOT yet normalized for production.

## Rules

1. Do not silently edit raw source material.
2. Normalized/verified datasets belong in `data/metadata/`.
3. M1 owns symbol verification, series mapping and effective dates.
4. If a platform symbol differs from the guide, preserve both.
5. Raw files are evidence; they are not automatically executable configuration.
