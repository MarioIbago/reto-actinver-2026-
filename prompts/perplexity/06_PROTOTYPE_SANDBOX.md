# PERPLEXITY PRO — CREATE FILES / APPS SANDBOX

Use only if your Pro account currently exposes Create files and apps.

Goal:
build a temporary report, spreadsheet, dashboard, or simple prototype to explore an idea.

Rules:
- DO NOT modify the production Reto Actinver repository;
- use a separate project/sandbox;
- mark all output PROTOTYPE;
- do not embed secrets;
- document dependencies and assumptions;
- keep data schemas portable so Codex can reimplement cleanly;
- no automated Actinver order execution.

Good uses:
- research report formatting;
- universe spreadsheet;
- qualitative event dashboard;
- news-source matrix;
- simple UI mockup.

Bad uses:
- core backtester;
- production data engine;
- validation engine;
- Tournament Brain;
- anything that becomes source-of-truth code.

At completion provide:
1. what was built;
2. files created;
3. assumptions;
4. what Codex should reimplement;
5. what should be discarded.
