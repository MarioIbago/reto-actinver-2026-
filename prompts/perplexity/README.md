# Perplexity Pro Prompts

These prompts define Perplexity Pro as the project's live-web / qualitative research layer.

They do NOT assume access to Perplexity Computer.

Recommended use:
1. create/use a dedicated Perplexity Project if available;
2. upload the Actinver eligible-universe file;
3. paste `00_GLOBAL_ROLE.md` into project/custom instructions when practical;
4. run task-specific prompts manually using Pro Search or Research.

Files:
- `01_COMPANY_DOSSIER.md`
- `02_NEWS_EVENT_SCAN.md`
- `03_OVERNIGHT_INTELLIGENCE.md`
- `04_SOURCE_VERIFICATION.md`
- `05_RESEARCH_TO_CODEX_HANDOFF.md`
- `06_CREATE_FILES_SANDBOX.md`

Core rule:
Perplexity researches and verifies current web information.
Codex owns production code.

If automatic tasks/Computer are not present in the user's account, all monitoring prompts are run manually.
