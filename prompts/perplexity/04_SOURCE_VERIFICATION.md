# PERPLEXITY PRO — SOURCE VERIFICATION / FACT CHECK

Use the global role prompt first.

Claim to verify:
[CLAIM]

Task:
determine whether the claim is:
- VERIFIED;
- PARTIALLY VERIFIED;
- OUTDATED;
- CONTRADICTED;
- UNSUPPORTED.

Search for the strongest primary source first.

Return:
1. verdict;
2. exact source;
3. date/time;
4. what the source actually says;
5. what the claim adds or distorts;
6. contradictory sources;
7. confidence;
8. whether the project should update documentation/config.

Do not smooth over ambiguity.
