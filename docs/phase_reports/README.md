# Phase Reports

Every completed milestone must leave a closure report here:

`<PHASE>_REPORT.md`

Minimum contents:
- scope completed;
- files changed;
- commands/tests/workflows executed;
- PASS/FAIL evidence;
- artifacts;
- architectural decisions;
- limitations;
- technical debt;
- blockers;
- whether exit criteria were satisfied;
- exact recommended next step.

A phase does not pass because files exist. It passes because its gate has evidence.
